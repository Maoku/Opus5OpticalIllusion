# 目視チェックリスト

[IMPLEMENTATION_PLAN.md §9](IMPLEMENTATION_PLAN.md) の「目視チェックリスト」。
各項目を **PC日本語 / PC英語 / スマホ日本語 / スマホ英語** の4条件で確認する。

URL パラメータで条件を作れる:

| 条件 | URL |
|---|---|
| PC 日本語 | `?lang=ja` |
| PC 英語 | `?lang=en` |
| スマホ相当（タッチ UI 強制） | `?lang=ja&touch=1` |
| レイアウト崩れ検証（疑似ロケール） | `?pseudo=1` |

`?touch=1` は実機の代わりにならない。バーチャルパッドと文脈ボタンの**導線**を
確認するためのもので、実際の指の当たり・発熱・色再現は実機でしか分からない。

### Room D の追加展示だけの観点

- [ ] **D3 の変化が「バグ」に見えない。** 変化は必ず 1 フレームで完了し、
      視界に入っている個体・直前に注視した個体は絶対に変わらない（ROOM_D §5）
- [ ] D3 の集計板は**一周し終えるまで出ない**。先に見えると錯視が成立しない
- [ ] D5 の影が 2 つとも読める。スクリーンの外へ光が漏れて、部屋の壁に
      **2 つ目の影**を作っていない
- [ ] D5 のダイヤルを一周させると「意味のある角度」を 2 回通る
- [ ] D1 の字が両方の視点で読める。断片が重なって潰れていない
- [ ] D1 のグロスラベルは **字が結ばれた後**に出る。日本語では出ない（§5.4）
- [ ] D1 の背景に明るい面（D5 のスクリーンの表）が入っていない

### 明度・色が成立条件の展示（要注意）

チェッカーシャドウ・くぼんだ顔・D6 は `brightnessCritical` を立ててある。
**後処理・トーンマッピング・画質プリセットを触ったら必ず再検証すること。**

チェッカーシャドウの校正値（high / gallery の環境光 / ACES）:

| 位置 | 期待値 |
|---|---|
| 影の外の明タイル | 約 232 |
| **A: 影の外の暗タイル** | **163** |
| **B: 影の中の明タイル** | **163** |
| 影の中の暗タイル | 約 60 |

A と B が数階調以上ずれていたら錯視は成立していない。
`src/exhibits/checkerShadow.ts` の `CALIBRATION` を実測し直す。
