# 目視チェックリスト

[IMPLEMENTATION_PLAN.md §9](IMPLEMENTATION_PLAN.md) の「目視チェックリスト」。
各項目を **PC日本語 / PC英語 / スマホ日本語 / スマホ英語** の4条件で確認する。

URL パラメータで条件を作れる:

| 条件 | URL |
|---|---|
| PC 日本語 | `?lang=ja` |
| PC 英語 | `?lang=en` |
| スマホ相当（タッチ UI 強制） | `?lang=ja&touch=1` |
| レイアウト崩れ検証（疑似ロケール） | `?pseudo=1` |

`?touch=1` は実機の代わりにならない。バーチャルパッドと文脈ボタンの**導線**を
確認するためのもので、実際の指の当たり・発熱・色再現は実機でしか分からない。

### 明度・色が成立条件の展示（要注意）

チェッカーシャドウ・くぼんだ顔・D6 は `brightnessCritical` を立ててある。
**後処理・トーンマッピング・画質プリセットを触ったら必ず再検証すること。**

チェッカーシャドウの校正値（high / gallery の環境光 / ACES）:

| 位置 | 期待値 |
|---|---|
| 影の外の明タイル | 約 232 |
| **A: 影の外の暗タイル** | **163** |
| **B: 影の中の明タイル** | **163** |
| 影の中の暗タイル | 約 60 |

A と B が数階調以上ずれていたら錯視は成立していない。
`src/exhibits/checkerShadow.ts` の `CALIBRATION` を実測し直す。

## 2. 導線と UI

- [ ] 入場ボタンで入場できる（全画面化に失敗する環境でも止まらない）
- [ ] エントランスの案内板が入場位置から読める
- [ ] 出入口の上の部屋名サインで順路が分かる
- [ ] ヒントを一度も押さなければ、解説が一切目に入らない
- [ ] ヒント → タネあかし → 元に戻す、が全展示で往復する
- [ ] 展示から離れるとヒントが自動で畳まれ、reveal も巻き戻る
- [ ] 展示一覧からワープでき、Opus 棟は開錠前「未開放」と出る
- [ ] Room A〜C を6点見ると Opus 棟が開錠し、告知が出る
- [ ] 言語切替がリロードなしで効く（UI・ワールド内の板の両方）
- [ ] 設定の各項目が即座に反映される

## 3. アクセシビリティ・酔い対策

- [ ] キーボードだけで、入場 → 移動 → 視点 → ヒント → 一覧 → 設定まで到達できる
- [ ] パネルにフォーカスがあるとき Tab がフォーカス移動として働く（ゲーム側に奪われない）
- [ ] `prefers-reduced-motion` でスナップが短縮され、回転 reveal が段階送りになる
- [ ] `prefers-reduced-motion` で D2 が完全に無効化される
- [ ] 設定の「縮んでいく部屋」トグルで D2 を単独で切れる
- [ ] 展示一覧のワープだけで全展示に到達できる（歩行不要）
- [ ] ヒントの本文が実 DOM テキストで読み上げられる

## 4. モバイル

- [ ] 左半分のドラッグで移動、右半分で視点。左右同時操作ができる
